# Myriad docs

Myriad is a free, open-source utility client for Minecraft {"26.2"} on Fabric. Its menu is a tiling window manager,
every module comes from an addon, and the stock modules pass Grim on 2b2t.

These docs have two halves.

<Cards num={2}>
  <Cards.Card title="Using Myriad" href="/docs/use" arrow>
    Installing, the menu and its keys, modules and settings, control panels, macros, themes, sharing your setup. No
    programming needed.
  </Cards.Card>
  <Cards.Card title="Developers" href="/docs/develop" arrow>
    Writing addons: modules, settings, events, the menu, rendering, the services, hooks, shared configs, publishing.
    With complete, working code.
  </Cards.Card>
</Cards>
