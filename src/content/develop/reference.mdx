# API reference map

Everything an addon uses is under `dev.myriadclient.api`. The [javadoc](/api/) (the latest release's, also in the
`-javadoc` and `-sources` jars on Myriad's maven, and so in your IDE) documents every class and method; this is a
map of where things are.

## The tiers

The API comes in four tiers. They differ in what they're for and how they change, not in how you use them:

| Tier | Packages | What it is |
|---|---|---|
| **Kernel** | `addon`, `module`, `setting`, `event`, `registry`, `config`, `hook`, `command`, `job` | the contract every addon is written against: it changes only with a major release |
| **Systems** | `service`, `elytra`, `control`, `share`, `ui.Desktop` | each arbitrates something shared (one player, one look, one hand, one packet budget, one glide) or runs a feature every addon plugs into |
| **UI** | `ui`, `ui.widget`, `ui.hud`, `ui.layout`, `render.Canvas` | the window manager and the drawing primitives |
| **Libraries** | `combat`, `world`, `build`, `map`, `render`, `util` | helpers: the shared vocabulary, so addons don't each re-derive it. They cost nothing until called |

Something goes into core when two addons have made it themselves, or when it arbitrates a shared resource; it stays in
an addon when it integrates another mod, holds a product's own policy, or is one addon's domain.

## The packages

| Package | What's in it |
|---|---|
| `api` | `Myriad`, the static entry point to everything (`Myriad.modules()`, `Myriad.placement()`, `Myriad.jobs()`...) |
| `api.addon` | `MyriadAddon`, `AddonContext`, `Addon`, `AddonState`, `AddonSettings`, `AddonStorage` |
| `api.module` | `Module`, `Modules` (lookups, `guard`, `suspend`), `ModuleGroup`, `Tag`, `Tags` (the shared ones), `ModuleRegistry` |
| `api.setting` | `Setting`, `Settings`, `SettingGroup`, `SavedSettings`, `SettingColor`, and every setting type |
| `api.event` | `Subscribe`, `HandlerThread`, `Priority`, `EventBus`, `Subscription`, `ListenerFlag`, `Cancellable` |
| `api.event.events` | every event ([Events](/docs/develop/events)) |
| `api.registry` | `Registry`, `Identified` |
| `api.config` | `ConfigManager`: profiles |
| `api.hook` | `Hook`, `HookHandler`, `HookCall`, `HookBuilder`, `Match`, `Service`, `Replacement`, `ReplacementBuilder`, `Contribution`, `Hooks` |
| `api.command` | `Command`; `api.command.arguments`: `Arguments` and the argument types |
| `api.job` | `Step` (and `Step.Run`), `Steps`, `MaterialSource`, `Job`, `Jobs`, `JobContext`, `Progress`, `Why`, `JobEvent` |
| `api.service` | `Rotations`, `Inventory`, `Placement`, `Breaking`, `Building`, `Containers`, their standard settings (`RotationSettings`, `PlacementSettings`, `BreakingSettings`, `BuildingSettings`), `AntiCheat`, `PacketLimits`, `TickSpeed`, `ServerStats`, `Friends`, `Notifications`, `KeyAction` |
| `api.elytra` | `Elytra`, `Flight`, `NoDurability`, `ChestSwap`, `GlideHold` |
| `api.control` | `ControlPanel`, `Controls`, `ControlPreset` |
| `api.share` | `ConfigShares`, `ConfigShare` |
| `api.ui` | `Panel`, `WidgetPanel`, `PanelType`, `Desktop`, `Window`, `TitleControl`, `BarWidget`, `Icons`, `Theme`, `ThemeSettings`, `ThemePalette`, `SettingWidgets`; `api.ui.widget`: the widgets; `api.ui.hud`: `HudPanel`, `TextHudPanel`, `HudStyle`, `ItemHud`; `api.ui.layout`: `Layout` |
| `api.render` | `Canvas`, `Renderer3D`, `ShapeBuilder`, `WorldMesh`, `MeshBuilder`, `HighlightStyle`, `HighlightSettings`, `BoxStyle`, `EntityGroups`, `WorldLabel`, `FadeMap`, `Ghosts`, `PlayerHeads`, `Projection`, `Animated`, `MyriadLogo` |
| `api.combat` | `Targets`, `TargetSettings`, `Damage`, `Threats`, `Crystals`, `Trajectory` |
| `api.world` | `ChunkCache`, `BlockScan`, `Holes`, `ChunkAge` |
| `api.build` | `Blueprint`, `Target`, `Build`, `BlockRules` |
| `api.map` | `Maps`, `Waypoint` (Xaero's Minimap, when installed) |
| `api.util` | `Client`, `Threads` (with `@RenderThread`, `@AnyThread`), `TickBudget`, `TickCached`, `Ticks`, `Timer`, `RateCounter`, `MyriadId`, `Keybind`, `Texts`, `Format`, `ChatMessages`, `Http`, `Async`, `Entities`, `BlockInfo`, `ItemInfo`, `ItemMatch`, `Reach`, `Interactions`, `Packets`, `Mining`, `Movement`, `Positions`, `MathUtil`, `Slots`, `Baritone`, `FakePlayers`, `ColorUtil` |
| `api.mixin` | `CompatMixinPlugin` |

`Category` and `Categories` (`api.module`) and `Tasks` (`api.service`) are deprecated and go in 1.0: use tags and
groups, and [jobs](/docs/develop/jobs).
