# API reference map

Everything an addon uses is under `dev.myriadclient.api`. The javadoc (in the `-sources` and `-javadoc` jars on
Myriad's maven, and in your IDE) documents every class and method; this is a map of where things are.

| Package | What's in it |
|---|---|
| `api` | `Myriad` (the static entry point to everything), `MyriadApi` |
| `api.addon` | `MyriadAddon`, `AddonContext`, `Addon`, `AddonSettings`, `AddonStorage` |
| `api.module` | `Module`, `Modules` (lookups), `Category`, `Categories` (the shared ones), `ModuleRegistry` |
| `api.setting` | `Setting`, `Settings`, `SettingGroup`, every setting type, `SettingColor`, `SavedSettings` |
| `api.event` | `Subscribe`, `Priority`, `EventBus`, `Subscription`, `Cancellable` |
| `api.event.events` | every event |
| `api.command` | `Command`; `api.command.arguments`: `Arguments` and the argument types |
| `api.service` | `Rotations`, `Inventory`, `Placement`, `Breaking`, `Building`, `Containers`, `Tasks`, `PacketLimits`, `AntiCheat`, `TickSpeed`, `ServerStats`, `Friends`, `Notifications`, `KeyAction` |
| `api.hook` | `Hook`, `HookHandler`, `HookCall`, `HookBuilder`, `Match`, `Service`, `ReplacementBuilder`, `Replacement`, `Contribution`, `Hooks` |
| `api.share` | `ConfigShares`, `ConfigShare` |
| `api.control` | `ControlPanel`, `Controls`, `ControlPreset` |
| `api.elytra` | `Elytra`, `NoDurability`, `ChestSwap`, `GlideHold` |
| `api.build` | `Blueprint`, `Target`, `Build` |
| `api.combat` | `Targets`, `TargetSettings`, `Damage`, `Threats`, `Crystals`, `Trajectory` |
| `api.world` | `ChunkCache`, `BlockScan`, `Holes` |
| `api.render` | `Canvas`, `Renderer3D`, `ShapeBuilder`, `WorldMesh`, `HighlightStyle`, `HighlightSettings`, `BoxStyle`, `EntityGroups`, `WorldLabel`, `FadeMap`, `Projection`, `Animated`, `MyriadLogo` |
| `api.ui` | `Panel`, `WidgetPanel`, `PanelType`, `Desktop`, `Window`, `TitleControl`, `BarWidget`, `Theme`, `ThemeSettings`, `ThemePalette`; `api.ui.widget`: the widgets; `api.ui.hud`: `HudPanel`, `TextHudPanel`, `HudStyle`, `ItemHud`; `api.ui.layout`: `Layout` |
| `api.util` | `Client`, `MyriadId`, `Keybind`, `Texts`, `Http`, `Async`, `TickCached`, `Timer`, `Entities`, `BlockInfo`, `ItemInfo`, `Reach`, `Interactions`, `Packets`, `Mining`, `Movement`, `Positions`, `MathUtil`, `Slots`, `Baritone`, `FakePlayers`, `ColorUtil`, `Format` |
| `api.mixin` | `CompatMixinPlugin` |
| `api.registry` | `Registry`, `Identified` |
