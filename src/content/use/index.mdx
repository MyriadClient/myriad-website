# Getting started

Myriad is a Fabric mod. It adds a menu (a tiling window manager, like a desktop inside Minecraft) and a system of
addons that provide the modules. The stock modules come in **Myriad Essentials**, which most people install alongside
Myriad itself.

## Install

<Steps>
### Install Fabric

Install the [Fabric loader](https://fabricmc.net/use/installer/) for Minecraft 26.2, and put the
[Fabric API](https://modrinth.com/mod/fabric-api) in your `mods` folder.

### Add Myriad and Essentials

Download `myriad-<version>.jar` from [Myriad's releases](https://github.com/MyriadClient/myriad-core/releases/latest)
and `myriad-essentials-<version>.jar` from [Essentials' releases](https://github.com/MyriadClient/myriad-essentials/releases/latest),
and put both in `mods`.

### Start the game

Myriad's title screen appears, in Myriad's colours, with the usual buttons plus one for the Myriad menu.
</Steps>

<Callout type="info">
  Myriad keeps itself and your addons up to date: when there's a new version, a notification says so, and the
  **Addons** window installs it. Nothing installs without you asking.
</Callout>

## Open the menu

The menu opens with the **mod key** and a number. The mod key is <kbd>Alt</kbd> unless you change it.

| Keys | What it does |
|---|---|
| <kbd>Alt</kbd>+<kbd>1</kbd> … <kbd>9</kbd> | Opens the menu on that workspace. The same keys again close it. |
| <kbd>Alt</kbd>+<kbd>Space</kbd> | Opens the **launcher** on its own, over the game: type a module's name and press <kbd>Enter</kbd>. |
| <kbd>Esc</kbd> | Closes the menu. |

The keys are also in Minecraft's **Options → Controls → Key Binds**, under *Myriad*, where you can change them. If you'd
rather open the menu with a single key (like <kbd>Right Shift</kbd>), bind **Open Menu** there.

## Turn on a module

Each window in the menu holds one addon's modules in one category, like **Combat · Essentials**. Click a module to turn
it on or off; right-click it (or click the arrow) to see its settings.

The quickest way is the launcher: press <kbd>Alt</kbd>+<kbd>Space</kbd>, type part of a name (`free look`), and press
<kbd>Enter</kbd>.
