# Addons and updates

Modules come from **addons**: ordinary Fabric mods made for Myriad. Install one by putting its jar in `mods` next to
Myriad's.

| Addon | |
|---|---|
| [Myriad Essentials](https://github.com/MyriadClient/myriad-essentials) | the stock modules and HUD elements |
| [Myriad Boze](https://github.com/MyriadClient/myriad-boze) | Boze's modules in Myriad's menu |
| [Myriad Omarchy](https://github.com/MyriadClient/myriad-omarchy) | themes that follow your Omarchy system theme |

## The Addons window

Open **Addons** from the launcher. It lists every addon with its version and links, and each addon's own settings.

**Updates**: Myriad checks each addon's releases. When there's a new version, a badge shows it, and **Update** installs
it (it takes effect the next time you start the game). The switch in the title bar turns checking off; the buttons
beside it check now and update everything. From chat: `.update check`, `.update all`.

If an addon fails to start, Myriad takes out everything it added and carries on without it. The Addons window shows
why it failed.
