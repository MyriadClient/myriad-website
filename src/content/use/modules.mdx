# Modules and settings

A **module** is one feature: Free Look, Kill Aura, Auto Eat. Addons provide them. Each sits in a category window in
the menu.

## On and off

Click a module to turn it on or off. A tinted bar on the left of its row means it's on. From chat, `.toggle <module>`
does the same (`.toggle free_look on`).

When a module turns on or off, a line in chat says so. Turn that off per module with its **Chat Feedback** setting.

Now and then a module holds another off while it works: Stash Hunter's Search keeps Elytra Fly and Auto Armor off while
it flies, so they don't fight over the elytra. The held module's row says **suspended by Search** (and the Module
List shows it faded); it comes back on by itself when Search is done, and your profile keeps it as on. Turning it on
meanwhile only takes effect afterwards; turning it off means it stays off.

## Settings

Right-click a module, or click the arrow at the end of its row, to unfold its settings. Settings come in groups; the
first is open, later ones start folded.

| Kind | Looks like |
|---|---|
| On/off | a switch |
| A number | a slider (click the value to type one) |
| A choice | a dropdown |
| A colour | a swatch: a fixed colour, a rainbow, or one of the theme's colours (so it changes with the theme) |
| A key | a bind button: click, then press a key or mouse button |
| A list | blocks, items, entities, modules or text, with a picker |
| A position | `x y z`, with a **Here** button |
| A file | a path, with the system file picker |

Hover a setting to see what it does. Some settings appear only when they matter: a module's *Range* might only show
while its *Mode* uses a range.

`.set <module> <setting> <value>` changes a setting from chat, and `.set <module>` lists them. A value is written
the way the setting shows it, so what you see can be typed back. A list takes the whole list (`2b2t.org, 6b6t.org`),
or `add <entry>`, `remove <entry>` or `clear`. `.reset <module>` puts every setting back to its default.

## Keybinds

Every module has a **Keybind** (in its *Module* group, at the bottom of its settings): press it in game to turn the
module on or off. Hold <kbd>Ctrl</kbd>, <kbd>Alt</kbd>, <kbd>Shift</kbd> or <kbd>Super</kbd> while you press the key to
bind a combination like <kbd>Ctrl</kbd>+<kbd>T</kbd>. Mouse buttons work too. `.bind <module> <key>` does it from chat:
`.bind tunnel t`, `.bind hole_esp ctrl+t`, `.bind zoom mouse5`, `.bind tunnel none` to unbind.

A key press runs only the closest match. With one module on <kbd>T</kbd> and another on <kbd>Ctrl</kbd>+<kbd>T</kbd>,
<kbd>Ctrl</kbd>+<kbd>T</kbd> runs only the second. A combination nothing is bound to falls back to the plain key:
<kbd>Shift</kbd>+<kbd>T</kbd> still runs the <kbd>T</kbd> bind, so you can sneak and toggle at once. Two things bound
to the very same keys both run. This goes for every Myriad bind: modules, control panels, macros and global actions like Open Menu.

- **Hold**: on while the key is held, off when you let go. Good for Zoom or Free Look.
- **Show In List**: whether the Module List HUD element shows it.

The **Keybinds** window (<kbd>Alt</kbd>+<kbd>K</kbd>) lists every bind in one place: modules, the menu's own keys, and
global actions.

<Callout type="info">
  A setting with a coloured tag beside its value is being set by something else for now, like a control panel. See
  [Setting layers](/docs/use/setting-layers).
</Callout>
