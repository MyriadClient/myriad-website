# The launcher

The launcher is the fastest way to do almost anything. Press <kbd>Alt</kbd>+<kbd>Space</kbd>, in game or in the menu,
and start typing.

It finds modules, control panels, macros, windows, categories, themes, profiles and workspaces. The search is fuzzy:
`frlk` finds *Free Look*.

| Key | In the launcher |
|---|---|
| <kbd>Enter</kbd> | run the top result: toggle a module, open a window, apply a theme |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> or right-click | the other action: a module's settings instead of toggling it |
| <kbd>Ctrl</kbd>+<kbd>j</kbd> / <kbd>Ctrl</kbd>+<kbd>k</kbd>, or the arrows | move through the results |
| <kbd>Esc</kbd> | close it |

Opened over the game (not in the menu), the launcher closes once it's done what you asked, and you're back playing.
Something that needs the menu (a window, settings) opens the menu for you.

## Filters

Two symbols narrow the results, on their own or with text:

- **`@addon`** keeps one addon's things. Any part of its name or id works: `@ess` is Essentials, `@stash` is Stash Hunter.
- **`#kind`** keeps one kind, or one category: `#panel`, `#control`, `#macro`, `#theme`, `#profile`, `#render`,
  `#combat`, `#movement`…

| Type | You get |
|---|---|
| `#control` | every control panel |
| `@ess #render` | Essentials' render modules |
| `#panel` | every window you can open |
| `@stash` | everything from Stash Hunter |
| `#macro kit` | macros with "kit" in the name |

## Making things

Whatever you type can become something new: the last two results are **New macro: …** and **New control panel: …**,
named after what you typed. See [Macros](/docs/use/macros) and [Control panels](/docs/use/control-panels).
