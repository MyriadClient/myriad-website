# Questions

### The menu doesn't open

Check the mod key in Minecraft's **Controls → Key Binds → Myriad**: another mod (or your system) might use
<kbd>Alt</kbd>+number. Pick another mod key under **Theme → Preferences**, or bind **Open Menu** to one key.

### A module does nothing on 2b2t

Check the [anti-cheat profile](/docs/use/anti-cheat): `.anticheat` says what's in effect. Some features (Air Place
on current Grim, Elytra Fly's Control) don't work where Grim runs, and say so.

### My settings changed by themselves

Something may be [layered](/docs/use/setting-layers) over them: a control panel that's on, or a module using it. The
setting shows a tag with who. Turn that off and yours are back.

### Where are my files?

In `.minecraft/myriad/`. See [Profiles](/docs/use/profiles#your-files).

### Reporting a bug

Run `.diagnostics` (it copies what's useful to the clipboard) and open an issue on
[GitHub](https://github.com/MyriadClient/myriad-core/issues).
