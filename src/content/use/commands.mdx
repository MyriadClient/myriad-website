# Commands

Myriad's commands start with `.` (change it with `.prefix`). They autocomplete in chat and in the Console window
(<kbd>Alt</kbd>+<kbd>Return</kbd>).

| Command | |
|---|---|
| `.toggle <module> [on\|off]` | turn a module on or off |
| `.bind <module> <key\|none>` | bind a module: `t`, `ctrl+t`, `shift+alt+f6`, `mouse5`, `rmb` |
| `.set <module> [setting] [value]` | change a setting (`.set esp colors.players #FF00FFAA` when two groups share a name) |
| `.reset <module>` | a module's settings back to their defaults |
| `.modules`, `.binds` | list modules (click to toggle) and binds |
| `.control [on\|off\|toggle <name>]` | [control panels](/docs/use/control-panels) |
| `.macro [run\|new\|delete <name>]` | [macros](/docs/use/macros) |
| `.share …` | [shared configs](/docs/use/sharing): `module`, `addon`, `panel`, `wheel`, `theme`, `import`, `try`, `delete` |
| `.profile [load\|save\|delete <name>]` | [profiles](/docs/use/profiles) |
| `.theme <preset>` | apply a theme |
| `.render [shader\|box]` | how modules draw what they show: [Shader or Box](/docs/use/menu#render) |
| `.friend add\|remove\|list` | friends (modules leave them alone) |
| `.anticheat …` | [anti-cheat profile](/docs/use/anti-cheat) |
| `.hooks [on\|off <name> \| why <module>]` | [what addons changed](/docs/use/hooks) |
| `.addons`, `.update [check\|all\|<addon>]` | addons and updates |
| `.cape [on\|off]` | Myriad's cape |
| `.profiler [on\|off]` | where the time goes, by module |
| `.jobs`, `.job pause\|resume\|cancel <id\|module\|all>` | [jobs](/docs/use/jobs): list, pause, resume, cancel |
| `.panic` | turn every module off |
| `.menu` | open the menu |
| `.reload` | read the profile from disk again |
| `.diagnostics` | copy versions, addons and settings for a bug report |
| `.say <message>` | send a message that starts with the prefix, as chat |
| `.fakeplayer add\|remove\|clear\|list` | client-side dummy players, for testing |
| `.disconnect` | leave the server |
| `.help` | all of this |
