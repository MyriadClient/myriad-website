# Anti-cheat profile

Servers check different things. On one running **Grim** (2b2t, for one), Myriad's modules rotate before acting, click
only faces you can see, move along the direction they send, mine when Grim allows, and click in your inventory only
while you stand still. On a server with only Minecraft's own checks, they act as fast as it lets them.

**Auto** (the default) works out which a server is: Grim once the server sends the steady pings anti-cheats like it
use, or at once for servers known to run it (2b2t). You can pick yourself in the **Profiles** window, or with:

| Command | |
|---|---|
| `.anticheat` | what's in effect, and what Auto detected |
| `.anticheat auto` / `grim` / `vanilla` | choose |
| `.anticheat known add <host>` / `remove` | servers to treat as Grim from the moment you join |

Essentials is made for 2b2t and stays safe on Grim whichever you pick.
